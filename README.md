# موقع مؤسسة عيد الخيرية + لوحة التحكم

موقع ديناميكي بالكامل. كل محتوى الصفحة الرئيسية محفوظ في قاعدة بيانات **MySQL**، وبتتحكم فيه من **لوحة تحكم** على الرابط `/admin`.

- **الواجهة:** React، بنفس تصميم Figma Make، وبتدعم العربي والإنجليزي.
- **السيرفر:** PHP، بدون أي مكتبات خارجية. بيشتغل على أي استضافة cPanel عادية.
- **قاعدة البيانات:** MySQL. الجداول والمحتوى المبدئي بيتعملوا تلقائيًا.

---

## إيه اللي تقدر تعمله من لوحة التحكم؟

| الجزء | المتاح |
|---|---|
| **المنيو الرئيسية** | إضافة، تعديل، حذف، إظهار/إخفاء، ترتيب. فيها 3 مستويات: عنصر رئيسي، وتحته مجموعات (أعمدة القائمة الكبيرة)، وتحتها روابط. وكل قائمة ممكن يكون ليها بطاقة مميزة اختيارية. |
| **الصفحات الفرعية** | إضافة صفحات بروابط زي `/page/about`، وتعديل عنوانها ورابطها وأقسامها، وإخفاء/ترتيب/حذف. الصفحات المنقولة من الموقع القديم بتتضاف تلقائيًا مرة واحدة. |
| **أقسام الصفحة** | إضافة، حذف، نسخ، إظهار/إخفاء، ترتيب. فيه 14 نوع قسم، وتقدر تضيف من كل نوع أي عدد. |
| **محتوى كل قسم** | تعديل كل النصوص بالعربي والإنجليزي، والصور (رفع أو اختيار من المكتبة)، والأزرار والروابط. |
| **عناصر كل قسم** | الشرائح والحملات والأخبار والبطاقات وغيرها: إضافة، تعديل، حذف، إظهار/إخفاء، ترتيب. |
| **الإعدادات العامة** | الشعار، الشريط العلوي، السوشيال ميديا، أعمدة الفوتر، بيانات التواصل، الترخيص. |
| **الحسابات** | أكتر من مدير، وتغيير كلمة المرور. |

> **عشان تربط رابط في المنيو بقسم في الصفحة:** اكتب في خانة «المعرّف» بتاعة القسم كلمة مثل `impact`، وفي رابط المنيو اكتب `#impact`.

## الرفع على cPanel

كل ما ترفع تعديل على فرع `main`، GitHub Actions بيختبر الكود ويبني الموقع تلقائيًا، وبعدين يحط نسخة جاهزة في فرع **`production`**:
- فولدر `public/`: فيه كل ملفات الموقع.
- ملف `.cpanel.yml`: بيقول لـ cPanel ينسخ الملفات دي فين.

### أول مرة
1. **قاعدة البيانات:** افتح cPanel ← **Database Wizard**. اعمل قاعدة بيانات ومستخدم، وادّي المستخدم صلاحيات **ALL PRIVILEGES**.
2. **الدومين:** افتح cPanel ← **Domains** ← **Create A New Domain**. مثلًا اعمل `eid.hifzalnaema.com`.
   - لو مسار **Document Root** طلع مختلف عن `eid.hifzalnaema.com`، عدّل `DEPLOYPATH` في ملف `deploy/cpanel.yml`.
3. **الكود:**
   1. افتح cPanel ← **Git™ Version Control** ← **Create**.
   2. اكتب رابط الـ repo.
   3. بعد ما يخلص: **Manage** ← غيّر **Checked-Out Branch** لـ **production** ← **Update**.
4. **النشر:** من تبويب **Pull or Deploy**، دوس **Deploy HEAD Commit**.
5. **التجهيز:** افتح `https://الدومين/admin`. هيطلب منك بيانات قاعدة البيانات، واسم وكلمة مرور حساب المدير. املاهم، والموقع يبقى جاهز.

### بعد أي تعديل في الكود
1. ارفع التعديل على `main`، واستنى علامة ✓ في تبويب **Actions**.
2. في cPanel افتح **Git Version Control** ← **Manage** ← **Pull or Deploy**.
3. دوس **Update from Remote**، وبعدين **Deploy HEAD Commit**.

> **مش هتحتاج الخطوات دي لتعديلات المحتوى:** أي تعديل بتعمله من لوحة التحكم بيتحفظ في قاعدة البيانات على طول.
> **الملفات دي مش بتتأثر بالتحديثات:** الصور المرفوعة في فولدر `uploads`، وملف الإعدادات `api/config.php`.

## التشغيل على جهازك (للتطوير)

هتحتاج PHP 8 أو أحدث، وNode.js 20 أو أحدث، وMySQL.

```bash
npm run dev:api        # سيرفر PHP على المنفذ 3000
npm run dev:client     # الواجهة (Vite) على المنفذ 5173
```

افتح `http://localhost:5173/admin`، وأدخل بيانات قاعدة البيانات المحلية.

الاختبارات بتستخدم SQLite بدل MySQL:
```bash
npm test
```

## هيكل المشروع

```
client/src/
  site/                 الموقع العام
  admin/                لوحة التحكم
  shared/sectionTypes.js  تعريف أنواع الأقسام وحقولها
php/
  .htaccess             توجيه الطلبات (API والصفحات)
  api/index.php         كل مسارات الـ API
  api/db.php            الاتصال بقاعدة البيانات، وإنشاء الجداول تلقائيًا
  api/auth.php          تسجيل الدخول
  api/seed.json         المحتوى المبدئي (بيتولّد من tools/seed.js)
  uploads/              الصور المرفوعة
deploy/cpanel.yml       مسار النشر على cPanel
tests/api.test.js       اختبارات الـ API
```

### إضافة نوع قسم جديد (للمطورين)
1. عرّف النوع وحقوله في `client/src/shared/sectionTypes.js`.
2. اعمل المكوّن بتاعه في `client/src/site/sections.jsx`، وسجّله في `SECTION_COMPONENTS`.
