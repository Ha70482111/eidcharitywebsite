# موقع مؤسسة عيد الخيرية + لوحة التحكم

موقع ديناميكي بالكامل: كل محتوى الصفحة الرئيسية محفوظ في قاعدة بيانات **MySQL**، وتتحكم فيه من **لوحة تحكم** على الرابط `/admin`.

- **الواجهة:** React (نفس تصميم Figma Make)، ثنائية اللغة عربي / إنجليزي.
- **السيرفر:** Node.js بدون أي إطار عمل، ومحتاج مكتبة واحدة بس: `mysql2`.
- **الاستضافة:** جاهز يشتغل على **cPanel** (Setup Node.js App).

---

## إيه اللي تقدر تعمله من لوحة التحكم؟

| الجزء | المتاح |
|---|---|
| **المنيو الرئيسية** | إضافة، تعديل، حذف، إظهار/إخفاء، ترتيب. 3 مستويات: عنصر رئيسي ← مجموعات (أعمدة القائمة الكبيرة) ← روابط، مع بطاقة مميزة اختيارية لكل قائمة. |
| **أقسام الصفحة** | إضافة، حذف، نسخ، إظهار/إخفاء، ترتيب. فيه 14 نوع قسم، ومن كل نوع تقدر تضيف أي عدد. |
| **محتوى كل قسم** | تعديل كل النصوص بالعربي والإنجليزي، والصور (رفع أو اختيار من المكتبة)، والأزرار والروابط. |
| **عناصر كل قسم** | الشرائح والحملات والأخبار والبطاقات وغيرها: إضافة وتعديل وحذف وإظهار/إخفاء وترتيب. |
| **الإعدادات العامة** | الشعار، الشريط العلوي، حسابات السوشيال ميديا، أعمدة الفوتر، بيانات التواصل، الترخيص. |
| **الحسابات** | أكتر من مدير، وتغيير كلمة المرور. |

**أنواع الأقسام:** الواجهة الرئيسية (Hero)، أبواب الخير، الحملات، بطاقات صور طويلة، أرقام وإحصائيات، قصة، مشاريع بتبويبين، بطاقات على خلفية كحلي، بطاقات دعوة، الأخبار، الشركاء، بطاقات عامة، نص وصورة، شريط دعوة.

> **للربط من المنيو لقسم في الصفحة:** اكتب في خانة «المعرّف» للقسم كلمة مثل `impact`، وفي رابط المنيو اكتب `#impact`.

## الرفع على cPanel (خطوة بخطوة)

كل ما ترفع تعديل على فرع `main` في GitHub، بيحصل الآتي تلقائيًا:
- **GitHub Actions** بيبني الموقع.
- بيحط نسخة جاهزة للتشغيل في فرع اسمه **`production`**.

cPanel بيسحب الفرع ده بس، فمش محتاج تبني أي حاجة على السيرفر.

### 1) إنشاء قاعدة البيانات
1. cPanel ← **MySQL® Databases**
2. أنشئ قاعدة بيانات، مثلًا `eid`، واسمها الكامل هيبقى `cpaneluser_eid`.
3. أنشئ مستخدم وكلمة مرور.
4. من **Add User To Database** اربط المستخدم بالقاعدة، واختار **ALL PRIVILEGES**.

> مش محتاج تستورد أي ملف SQL. الجداول والمحتوى المبدئي بيتعملوا تلقائيًا أول ما السيرفر يشتغل.
> لو حابب تستوردهم يدويًا، الملفات موجودة في `database/schema.sql` و`database/seed.sql`، وتقدر تستوردها من phpMyAdmin.

### 2) سحب الكود من GitHub
1. cPanel ← **Git™ Version Control** ← **Create**
2. **Clone URL:** رابط الـ repo، مثلًا `https://github.com/USERNAME/REPO.git`
   - لو الـ repo **خاص (Private)**: من نفس الصفحة اعمل SSH key، وأضفه في GitHub من **Settings ← Deploy keys**، واستخدم رابط SSH.
3. **Repository Path:** مثلًا `eid-charity`
4. بعد الإنشاء: **Manage ← Pull or Deploy**، واختار الفرع **`production`** ← **Update from Remote**.

> **بديل من غير Git:** من GitHub افتح فرع `production`، ونزّله ZIP من **Code ← Download ZIP**، وارفعه وفك الضغط في File Manager.

### 3) تشغيل تطبيق Node.js
1. cPanel ← **Setup Node.js App** ← **Create Application**
2. اضبط الإعدادات دي:
   - **Node.js version:** 18 أو أحدث (يفضل 20)
   - **Application mode:** Production
   - **Application root:** `eid-charity` (نفس مسار الخطوة 2)
   - **Application URL:** الدومين بتاعك
   - **Application startup file:** `app.js`
3. في **Environment variables** أضف:

| الاسم | القيمة |
|---|---|
| `DB_HOST` | `localhost` |
| `DB_NAME` | اسم قاعدة البيانات الكامل |
| `DB_USER` | اسم المستخدم الكامل |
| `DB_PASSWORD` | كلمة المرور |
| `APP_SECRET` | (اختياري) أي نص طويل عشوائي |

4. اضغط **Create**، وبعدها **Run NPM Install**، وبعدها **Restart**.

### 4) أول دخول
- افتح الدومين، وهتلاقي الموقع شغال بالمحتوى المبدئي.
- افتح `https://الدومين/admin`. أول مرة هيطلب منك **إنشاء حساب المدير**.

### تحديث الموقع بعد أي تعديل في الكود
1. ارفع التعديل على `main`، واستنى علامة ✓ الخضراء في تبويب **Actions** على GitHub.
2. في cPanel: **Git Version Control ← Update from Remote**.
3. بعدها: **Setup Node.js App ← Restart**.

> تعديلات المحتوى من لوحة التحكم بتتحفظ في قاعدة البيانات مباشرةً ومش محتاجة الخطوات دي. والصور المرفوعة بتتحفظ في فولدر `uploads`، ومش بتتمسح مع التحديثات.

## التشغيل على جهازك (للتطوير)

محتاج Node.js 20 أو أحدث، وMySQL (مثلًا من XAMPP).

```bash
cp .env.example .env        # وعدّل بيانات قاعدة البيانات
npm install
npm run build               # يبني الواجهة في dist/
npm start                   # http://localhost:3000  و  /admin
```

أثناء تعديل الواجهة، شغّل الأمرين دول في نافذتين منفصلتين:
```bash
npm run dev:server          # السيرفر على 3000
npm run dev:client          # Vite على 5173 مع إعادة تحميل فورية
```

الاختبارات (محتاجة Node 22.5+، وبتستخدم SQLite المدمجة بدل MySQL):
```bash
npm test
```

## هيكل المشروع

```
app.js                  نقطة التشغيل (Startup file في cPanel)
server/
  index.js              السيرفر + تقديم الملفات
  api.js                كل مسارات الـ API
  db.js                 الاتصال بـ MySQL + إنشاء الجداول تلقائيًا
  auth.js               تسجيل الدخول (scrypt + توكن موقّع)
  seed.js               المحتوى المبدئي (من تصميم Figma)
database/               schema.sql و seed.sql للاستيراد اليدوي
client/src/
  site/                 الموقع العام
  admin/                لوحة التحكم
  shared/sectionTypes.js  تعريف أنواع الأقسام وحقولها
tests/api.test.js       اختبارات الـ API
.github/workflows/      البناء والنشر التلقائي
```

### إضافة نوع قسم جديد (للمطورين)
1. عرّف النوع وحقوله في `client/src/shared/sectionTypes.js`.
2. اعمل المكوّن بتاعه في `client/src/site/sections.jsx`، وسجّله في `SECTION_COMPONENTS`.

لوحة التحكم هتعرض الحقول تلقائيًا من التعريف.

## ملاحظات
- **بوابة الدفع مش مربوطة.** بطاقة التبرع بتبعت المتبرع لـ «رابط صفحة الدفع» اللي تحدده في قسم الـ Hero، ومعاه المبلغ والنوع والباب في الرابط. ولو الرابط فاضي، بتظهر رسالة إن الدفع غير متاح.
- **النشرة البريدية:** لو حطيت رابط في «رابط استقبال الاشتراكات» في الإعدادات، البريد بيتبعت له. غير كده بتظهر رسالة شكر بس.
- **الصور المرفوعة:** PNG أو JPG أو WEBP أو GIF، وأقصى حجم 5 ميجا.
- **تعديلات الوصولية المطبقة من المراجعة:** تباين الألوان، وأحجام مناطق اللمس، ومؤشرات التركيز، وزر «مرة واحدة / شهري» بعلامة ✓ مش باللون بس.
